# GitHub Automation

> See [Grey Sky Labs GitHub Automation Template](https://github.com/josephas-llc/greyskylabs/blob/main/templates/github-automation.md.template) for CI/CD setup instructions.

## Quick Start

1. Copy the workflow files from the template to your `.github/` directory
2. Enable Dependabot in repo settings
3. Enable CodeQL in Security settings

## What's Included

- **GitHub Actions CI** - Tests on every push/PR
- **TypeScript Check** - Catches type errors
- **Test Coverage** - Codecov integration
- **E2E Tests** - Playwright browser testing
- **Dependabot** - Weekly dependency updates
- **Auto-Release** - Builds on release creation
